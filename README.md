# National Park Visit Planner

Explore U.S. National Park Service sites, search for parks, filter by state, and view a park's details.

# Peterson Cordeiro's WDD 330 personal project. 

## Render

The website is published on Render, the link is [https://wdd330-national-park-planner.onrender.com/](https://wdd330-national-park-planner.onrender.com/).

## APIs used

[National Park Service API](https://www.nps.gov/subjects/developer/).
[Open-Meteo](https://open-meteo.com/en/docs).
